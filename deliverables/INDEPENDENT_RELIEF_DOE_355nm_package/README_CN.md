# 355 nm 独立双浮雕 DOE 线光方案包

本资料包包含两片独立设计的熔融石英浮雕 DOE、MATLAB R2019b 代码、加工数据和正式仿真结果。未使用 HOLO/OR 厂商专有相位或旧焦面方案代码。

## MATLAB R2019b 主程序

```matlab
cd('D:/work/git_share/laser_sim/deliverables/INDEPENDENT_RELIEF_DOE_355nm_package/02_matlab_code');
result = run_independent_relief_DOE_R2019b();
```

主程序从完全相干高斯束腰复场开始，设计 DOE 连续相位，施加实际横向保持单元和 32 级高度量化，并在联合优化过程中锁存满足宽度、倾角和曲率约束的历史最高均匀性加工相位。随后刷新 `03_fabrication_data` 与 `04_simulation_results/matlab_R2019b`。

## 冻结主配置

- 波长 355 nm；连续单模完全相干光；激光出口为束腰。
- 椭圆束腰全 1/e² 直径：X=1.0 mm、Y=1.1 mm；M²X=M²Y=1.2。
- 第一光学元件为球面对称负扩束镜；第一组圆对称扩束倍率 5.0×，允许设计范围 5–10×。
- DOE1 位于 Z=120 mm，DOE2 位于 Z=220 mm；间隔 100 mm，二者之间只有空气。
- DOE 后只对 Y 扩束；不将 X 扩大到约 54 mm，不设置后续 X 压缩镜组。
- YFL 位于 Z=570 mm，只对 Y 聚焦：fY=100 mm、fX=∞；目标面 Z=670 mm，工作距离 100 mm。
- 目标：X 全 1/e² 宽度 1.5 mm且近似平行；Y 全 1/e²宽度 1.0 µm。

## MATLAB R2019b 正式结果

- X 全 1/e²宽度：1.533032 mm，误差 +2.20%，满足 ±5%尺寸条件。
- Y 全 1/e²宽度：1.000000 µm。
- X 中央固定 90% 区域（1.35 mm）的 `Imin/Imax` 均匀性：**85.388434%**。
- X 平均波前倾角：4.437530 µrad，满足 ≤10 µrad。
- X 曲率边缘斜率：16.117134 µrad，满足 ≤50 µrad。
- 继续自由传播 100 mm 后，X 宽度变化：2.863850%，仅作衍射诊断，不作硬性验收。
- 最优加工相位出现在第 470 次联合量化迭代；主程序总搜索上限为 600 次。
- 原均匀性门槛为 90%；用户选择按当前约束下的最佳 85.388434% 结果输出，因此总验收标志仍为 0，不能写成达到 90%。

## DOE 加工定义

- 最大通光尺寸：50 mm；中央有效浮雕图形宽度：8 mm。
- 请求最小横向特征：5 µm；FFT网格向上取整后的实际加工单元节距：6.103516 µm，不小于请求值。
- 两片 DOE 均为沿 X 变化、沿 Y 等高延伸的一维结构。
- 32级浮雕、5张二进制光刻掩模。
- 熔融石英折射率 n(355 nm)=1.476071880。
- 理论 2π 浮雕深度 0.745685714 µm；高度步长 0.023302679 µm；最大保留高度 0.722383035 µm。
- 掩模 CSV 中 `1=开窗/曝光并刻蚀`，`0=保护`。

## 加工前边界

加工前必须确认激光椭圆短轴沿 X、两片 DOE 表面朝向、100 mm 轴向间距、横向和转角对准、掩模正负片、刻蚀选择比、深度偏差、侧壁角、355 nm增透膜和损伤阈值。85.388434% 是名义标量相干模型结果，不包含实际刻蚀误差、散射、污染和装调偏差。
